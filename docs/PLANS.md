# Unit testing

## Theme

Generate the tests for each Theme component. The code for each component live inside `@/components/theme`.

## UI

### Atomics

Generate the tests for each atomic component. The code for each component live inside `@/components/ui/atomics`. Exclude the `badge` and `buttons` folder the tests for the components living inside them already have been created.

### Components

Generate the tests for each compound component. The code for each component live inside `@/components/ui/components`.

### Lib

Generate the tests for each custom hook living inside the `@/lib` folder.

## App

Generate the tests for each page of the app. The code for each page live inside `@/app` and every file has the name `page.tsx`.

## Configuration file

You can find the vite configuration file in the `vitest.config.mts` file.
